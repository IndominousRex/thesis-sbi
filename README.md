# General information
1. Most information and templates can be found in [Stud.IP/Arbeitsgruppe: imes](https://studip.uni-hannover.de/dispatch.php/course/overview?cid=cd5306d665b727641a9acc4b4ed144e9). Here, you can find powerfull and high-quality templates for your thesis, for coding/plotting and for presentations. Your are strongly advised to use them.
2. Additional information and documents are provided via this repository and my [wiki page for student theses](https://wiki.projekt.uni-hannover.de/imes-promotion-ewering).
3. Jour Fixe: Takes place every second week, Monday, in presence (room 8142, 1. floor, imes Besprechungsraum A)
4. Protocol/Meetings: In a personal meeting, we will discuss your questions. The aim is to keep you on track, give you interesting ideas and to avoid that you waste valuable time. Thus, these meetings are for You, so You are responsible to use them efficiently. Prior to a meeting, please add a protocol entry in the README in which you specify a) concrete questions and b) your plan for the next weeks. **If the README is not updated prior to the meeting, the meeting will not take place.** Guiding questions for the protocol entry:
    - What did I do since the last meeting?
    - Does my current work contribute to solving the main task?
    - Where am I stuck and need help to solve a problem in order to proceed?
    - Where am I stuck and need input for a major (methodological) decision?
5. Before you ask for help in debugging your code, please try to solve coding issues yourself (e.g., using stackoverflow or by interpreting the error message)
